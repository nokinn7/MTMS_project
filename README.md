# 🚇 Metro Transport Management System (MTMS)

##  Project Overview

The Metro Transport Management System (MTMS) is a DBMS project designed to manage and organize the major operations of a metro transportation system.

The system stores and manages information related to passengers, smart cards, metro lines, stations, trains, routes, schedules, bookings, tickets, payments, employees, maintenance records, and journey history.

The project demonstrates how a real-world metro management system can be represented using a relational database, with different entities connected through appropriate relationships, primary keys, and foreign keys.


##  Objectives

The main objectives of this project are:

- Manage passenger information.
- Manage smart cards associated with passengers.
- Maintain information about metro lines and stations.
- Manage trains, routes, and schedules.
- Handle passenger bookings and ticket generation.
- Record payment details.
- Maintain employee information.
- Store train maintenance records.
- Maintain passenger journey history.
- Implement relationships between different entities using primary keys and foreign keys.


##  Main Entities

The system includes the following entities:

- Passenger
- Smart Card
- Metro Line
- Station
- Train
- Route
- Schedule
- Booking
- Ticket
- Payment
- Employee
- Maintenance Record
- Journey History
